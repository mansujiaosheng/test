## 4. 13401（CAN FD 桥）

- `connect` 后 **+25.6 ms 收到 FIN**，客户端 0 字节发送时也一样（10/10）⇒ accept-then-close，从不 read。
- 18+13 种协议载荷（DoIP/CAN/ISO-TP/TLS/HTTP/WS/h2/SOCKS5/MQTT/长度前缀/JSON）全部 0 字节回包。
- 与 cgw 组包级证据一致：`03_EVIDENCE/cgw/0520_newenv_13401_packetlevel.txt`。
- 解释：**开桥前是"关着的门"**，不是协议选错。

## 5. 判定

1. `10.226.197.5/6/7:8080` 当前**不可达**，原因是 IP 层无路径（路由器无 `10.226.197.0/24` 路由），不是主机/端口过滤。
2. 门户的"运行中"只表示容器在跑，不代表 VPN 可路由。
3. 打通前置：P1 平台侧路由；P2 打开 13401 桥（凭据在 OTA 工程包/后续任务）；P3 CGW 转发/代理面（当前没有）。
