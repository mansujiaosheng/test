# CGW · 第二个 UDS 节点 0x1220（新环境）

> 采集 2026-11-14 09:5x–10:1x（Asia/Shanghai），目标 **10.226.193.2:13400**（靶机重启后的新地址）。
> 完整逐条证据与复核命令见 [04_SOLVE/cgw/FINDINGS.md](../../04_SOLVE/cgw/FINDINGS.md)。
> 执行者：cgw-doip。

## 1. 实体与地址

| 项 | 值 |
|---|---|
| DoIP 实体 LA | `0x1000` |
| VIN | `CV622697F82A936A1`（hex `4356363232363937463832413933364131`） |
| EID / GID | `060000001000` / `000000000000` |
| further action | `0x00`（识别响应 33 字节，规范 32，多 1 字节） |
| 第二个节点 | **`0x1220`**，只能经**功能地址 `0xE442`** 到达 |
| CAN 诊断 ID（`22F1A0`） | `07E0/07E8/07E1/07E9`（两对请求/响应 ID） |

## 2. 两个节点的能力对比

| 能力 | `0x1000`（网关自身） | `0x1220`（经 `0xE442`） |
|---|---|---|
| `0x22` | ✅ 仅 `F190`(VIN)、`F1A0`(CAN ID 表) | ✅ 仅 `F1A3`（`7F2233` 安全拒绝） |
| `0x10` | ❌ `7F1011` | ✅ **只有 `10 03`**（`5003`）；`10 01/02/04/05/…` 全 `7F1012` |
| `0x27` | ❌ `7F2711` | ⚠️ 实现但**恒 `7F277E`**（任何子功能/会话/SA/带参都一样） |
| `0x31` | ❌ `7F3111` | ⚠️ 实现但**恒 `7F3133`**（任何 RID、01/03 都一样） |
| `0x2E` | ❌ `7F2E11` | ⚠️ 实现但**恒 `7F2E31`**（65536 个 DID 零数据探测全 0x31） |
| `0x23`/`0x19`/`0x3E` | ❌ `7F..11` | ❌ `7F..11` |

## 3. 关键判定

1. `0x1220` 是**唯一**实现会话、安全访问、例程的节点 ⇒ 题面「13400 诊断例程开 13401 CAN FD 桥」的例程大概率在它上面。
2. 但它的安全门**自相矛盾**：`0x27` 服务存在（0x7E 而不是 0x11/0x31），唯一可达会话 `0x03` 下仍判“子功能不在当前会话”，`0x10 01/02` 又被拒（0x12）⇒ 没有任何可达会话能让 `0x27` 成功。
3. `0x2E` 写表为空（全 DID 0x31），`0x31` 无参数探测全 0x33（安全优先于 RID 校验）。
4. ⇒ **开锁凭据不在 DoIP 协议本身**，应从链路上一段（TSP OTA 工程包 / 诊断票据 / T-BOX）获取，再回来一次性使用。继续在 DoIP 上猜子功能/RID 是低收益。

## 4. 判据（避免误判）

- `src=0x1000 + NRC 0x31` = 网关不认识该目标地址（不是“节点不存在”的证明）。
- `src=0x1220` = 真正到达第二个节点。
- 任何“无响应”必须换干净连接、单请求、≥3s 超时复验（长尾延迟 0.8–4s 有实测）。
